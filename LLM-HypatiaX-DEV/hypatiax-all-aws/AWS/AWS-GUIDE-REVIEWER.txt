Three files — here's how they fit together and what you do in order.

What you got
hypatiax-reproducibility.yaml — the CloudFormation template. This is the entire
infrastructure as code. Key things it does:
    • Pulls the API key from Secrets Manager at runtime, not from a parameter — so you
      can rotate the key any time without touching the template
    • Uploads a live heartbeat page to S3 immediately on boot, so reviewers see progress
      rather than a blank URL for 5+ hours
    • Runs the full CI v9 pipeline: Phase 0 (setup) → Phase 1 (exp1 74-case suite,
      exp1b, exp2-feynman NEW, exp2-sym, exp2-hyb, exp2, exp3, exp3b) →
      Phase 2 (supp) → Phase 3 (audit) → Phase 4 (figures + tables)
    • Generates the HTML summary + ZIP in Python, including per-equation tables for
      exp2-feynman (Feynman-30) and exp2 (6-method all-30), each with R², expression,
      and pass/fail
    • Persists the exp2_all30_checkpoint.json so equation-level progress survives
      Spot interruptions
    • Self-terminates cleanly; the S3 bucket auto-deletes after 45 days
    • Outbound-only security group — no SSH port open

REPRODUCIBILITY.md — drop this in your repo root. It has the Launch Stack badge,
a plain-English walkthrough for reviewers, environment table, pipeline phase summary,
cost breakdown, troubleshooting (including exp2-feynman vs exp2 result separation),
and the author-side key rotation instructions.

Makefile.repro — your operational runbook. Rename to Makefile or add to your existing one.


What to do now, in order

bash
# 1. Fill in your real values in the template:
#    - RepoUrl default  → your actual GitHub URL
#    - YOUR_EMAIL       → your contact email (appears on results page)

# 2. One-time AWS setup (creates S3 bucket + stores key in Secrets Manager)
make -f Makefile.repro setup-aws
# It will print the Secret ARN — paste it into the template's
# AnthropicKeySecretArn default field, then:

# 3. Publish
make -f Makefile.repro publish-repro-stack

# 4. Test it yourself (~$1 with PysrTimeout=500)
make -f Makefile.repro test-launch

# 5. When your key rotates (no template republish needed):
make -f Makefile.repro rotate-key


The key rotation concern — fully handled

The Secrets Manager approach means the template URL in your paper never changes.
When your key expires or you get a new one:
    • Run make rotate-key — takes 30 seconds
    • Reviewers who launch the stack after that automatically get the new key
    • Reviewers mid-run are unaffected (key was already fetched at bootstrap)
    • You never need to republish the template or update the paper's URL

The monthly $50 budget cap on the dedicated key is the last line of defence — even if
many reviewers run simultaneously, you can't be charged more than that in a month.
The key drives claude-sonnet-4-20250514 for LLM-augmented steps.


CI v9 changes to be aware of

exp1 now covers 74 cases (up from 15 in earlier versions). The CloudFormation stack
runs all 74 cases as a single sequential job internally; the 7-chunk split you see in
the GitHub Actions YAML (1-4, 5-8, 9-12, 13-28, 29-44, 45-59, 60-74) is a CI
parallelism detail that doesn't affect the stack.

exp2-feynman is a new standalone Phase 1 step (experiment_protocol_feynman_exp2.py).
It runs HypatiaX + NN baseline on all 30 Feynman equations and produces stats.json,
results.csv, table.tex, and report.html. It is separate from the 6-method comparison
suite (exp2-sym / exp2-hyb / exp2). Both sets of results appear in the ZIP and on
the summary page.

exp2 now uses run_comparative_suite_benchmark_v2.py --protocol all30 --resume.
Per-equation progress is checkpointed atomically to
hypatiax/data/results/comparison_results/exp2_all30_checkpoint.json — this file is
included in the results ZIP.

Environment pinned to Python 3.12, Julia 1.11, claude-sonnet-4-20250514.
