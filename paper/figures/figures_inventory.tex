\noindent\textbf{Generation source:} all 5 figures are produced by
\texttt{scripts/generate\_figures.py}; the two heatmaps are parsed
directly from the values printed in Table~\ref{tab:llm_ablation}, so
figure and table cannot disagree, and the seed sweep is drawn only from
\texttt{portfolio\_variance\_seed\_sweep.json} (no values are embedded in
the script; if that file is missing the figure is skipped rather than
drawn from stale data). If the \texttt{.tex} file cannot be found or
parsed, the two heatmaps fall back to
\texttt{exp1\_ablation\_results.json}. PDFs are written without a
creation timestamp, so re-running the script on unchanged inputs
reproduces them byte for byte. This is distinct from the benchmark
supplement's reproducibility figure set (regenerated from the
\texttt{noise\_sweep}/\texttt{sample\_complexity} v2 JSONs with
\texttt{--experiment suppB} and \texttt{--experiment suppB\_sc}), none of
which is embedded in the manuscript.
