The two API key decisions

If reviewers enter their own key: the template as written handles this — the
AnthropicApiKey parameter is NoEcho: true so it never appears in CloudFormation logs,
and it's stored in Secrets Manager then deleted with the stack.

If you want reviewers to need nothing: create a dedicated Anthropic key with a spending
limit (e.g. $50), store it in Secrets Manager as described above, and hard-code that
secret ARN in the template. This is more work and has obvious cost implications if many
reviewers run it — only worth doing for high-profile venues.

Q: Where will reviewers get the Anthropic API key?
A: Use the Secrets Manager approach — the key is pre-seeded by you and pulled at runtime.
Reviewers never handle it. The model used is claude-sonnet-4-20250514.


Smart concern — review cycles are unpredictable and keys expire or get rotated.
Here's how to handle both answers properly.

API key problem — solved with a budget-capped dedicated key + dead-man's switch

Don't use your main key. Create a dedicated reproducibility key with three layers of
protection:

Layer 1 — Anthropic spending limit
In your Anthropic console, create a new API key named hypatiax-repro-reviewers. Set a
monthly spending limit of $50 (enough for ~8–10 full reviewer runs at ~$4–5 of LLM calls
each, using claude-sonnet-4-20250514). When the budget is exhausted, the key stops
working but your main account is unaffected.

Layer 2 — AWS Secrets Manager rotation
Store the key in AWS Secrets Manager. This lets you update the key value at any time
without touching the CloudFormation template — reviewers always pull the current value
at launch time.

bash
aws secretsmanager create-secret \
  --name hypatiax/repro/anthropic-key \
  --description "Dedicated reviewer reproducibility key — budget capped at $50/mo" \
  --secret-string "sk-ant-YOUR-DEDICATED-KEY" \
  --region us-east-1

When your key rotates or you get a new one, just update the secret — no template
change needed:

bash
aws secretsmanager update-secret \
  --secret-id hypatiax/repro/anthropic-key \
  --secret-string "sk-ant-YOUR-NEW-KEY"

Layer 3 — Graceful degradation in the bootstrap
If the key is missing, expired, or over-budget, the pipeline continues without LLM
steps and the results page clearly marks which steps were skipped vs failed. Reviewers
still get all symbolic regression results (exp1 74-case suite, exp1b, exp2-feynman
Feynman-30 extrapolation, exp2-sym / exp2-hyb / exp2 6-method suite, exp3 / exp3b);
only the LLM-augmented comparison steps and paper-audit notebooks are affected.
